Información y Fuentes

Sobre este Dashboard

Este dashboard muestra la intensidad de tráfico en tiempo real (vehículos/hora) por tramo de calle en Valencia. Los datos son reales y se descargan en directo del Ayuntamiento de Valencia; se actualizan cada minuto.

Fuentes de Datos

  • Intensidad tráfico tramos (Ayuntamiento de Valencia)
  • Portal de datos abiertos de Valencia

Limitaciones

Es una lectura instantánea, no un histórico ni un IMD diario. Algunos tramos no tienen lectura o estado válido y se muestran como «sin datos».
