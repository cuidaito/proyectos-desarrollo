Información y Fuentes

Sobre este Dashboard

Este dashboard muestra el Índice Medio Diario de Vehículos (IMD) en las calles de Valencia. Los datos provienen de fuentes públicas del Ayuntamiento de Valencia y portales de datos abiertos.

Fuentes de Datos

  • Valencia OpenDataSoft
  • datos.gob.es
  • Institut Cartogràfic Valencià

Limitaciones

Este dashboard utiliza datos sintéticos de demostración. Para datos oficiales y actuales, consulta directamente los portales públicos del Ayuntamiento.
