# Dashboard IMD Valencia

Dashboard estático para visualizar el Índice Medio Diario (IMD) de vehículos en calles de Valencia: KPIs, gráficos (Chart.js), mapa (Leaflet), tabla, filtros, tema oscuro y exportación a CSV.

> Usa **datos sintéticos de demostración** generados en `data.js`.

## Uso local

Abre `index.html` en el navegador (sin build).

## Archivos

- `index.html`: estructura
- `styles.css`: estilos
- `config.js`: calles, colores y mapa
- `data.js`: generador de datos
- `script.js`: filtros y visualizaciones
